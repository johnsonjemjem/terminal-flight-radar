## ⚡ Core Features

- **✦ Simulated Boot Sequence**: Interactive Linux-style command line initialization process on load.
- **✦ Quick Track Hotkeys**: Instant tracking presets for Tokyo Haneda (HND) and Tokyo Narita (NRT) flight corridors (e.g., `AA169`, `AA175`, `AA167`).
- **✦ Live Radar Sweep Visuals**: Radial radar scan animation powered entirely by raw CSS animations.
- **✦ Operational JSON Uploads**: Drag-and-drop zone to import operational flight routing plans dynamically.
- **✦ Diagnostics Panel**: Auto-refresh interval toggles, real-time local clock (JST), API status queries, and system uptime logs.
- **✦ Responsive Design**: Tailored terminal view for desktop workstations and mobile card list view for portable screens.

## 🛠️ Tech Stack

- **Markup**: HTML5 Semantic Structure

## 🚀 How to Run Locally

Get the application running on your local machine in under a minute:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/johnsonjemjem/terminal-flight-radar.git
   ```
2. **Navigate into the project directory**:
   ```bash
   cd terminal-flight-radar
   ```
3. **Open the project**:
   - Double-click the `index.html` file to open it directly in your web browser, OR
   - Run it using VS Code's Live Server extension.
